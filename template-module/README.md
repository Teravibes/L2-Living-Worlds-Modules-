## Install

1. Download the latest release `.zip`, or copy this folder.
2. Place it in your server's `game/modules/` directory as `game/modules/example-module/`.
3. Enable it in the launcher and restart the server.

## Configuration

Settings live in `config/module.ini`. The important one:

- `Enabled` - master switch. Set to `True` and restart to turn the module on.
